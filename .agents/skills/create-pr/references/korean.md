# 한국어 풀 리퀘스트 절차

사용자가 “create a korean version pull request”를 요청했을 때 이 절차를 사용한다.

PR을 만들기 전에 저장소를 점검한다. 현재 브랜치가 대상 base 브랜치가 아닌지, 포함될 작업 트리 변경과 커밋이 무엇인지, 저장소의 일반적인 base 브랜치가 무엇인지 확인한다. 사용자의 관련 없는 변경은 보존한다.

PR 제목과 본문은 한국어로 작성한다. 사용자에게 보이는 변경 내용을 요약하고, 실제로 실행한 검증만 기재한다. 저장소에 기여 가이드나 PR 템플릿이 있으면 따른다. 실행하지 않은 테스트나 검사를 했다고 적지 않는다.

브랜치가 준비되고 푸시된 뒤에만 PR을 생성한다. 설정된 GitHub remote를 사용하고 생성된 PR URL을 알린다. base 브랜치, 범위, 인증을 안전하게 확정할 수 없으면 임의로 선택하지 말고 사용자에게 확인을 요청하거나 차단 사유를 보고한다.
